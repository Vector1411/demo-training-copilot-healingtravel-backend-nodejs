# 01_user_flows

## Guest Flow (PRD/Wireframe)
1) Truy cập website → Landing (G-01)  
2) Xem danh sách tour open  
3) Chọn tour → Tour Detail (G-02)  
4) Nhấn “Đăng ký tour” (chỉ khi open) → Form (G-03)  
5) Submit → success/error message  

## Admin Flow (PRD/Wireframe)
1) Truy cập → Admin Login (A-01)  
2) Login thành công → Dashboard (A-02)  
3) Điều hướng:
- Tour Management (A-03) → Create/Edit (A-04)
- Registration Management (A-05)
