# Copilot Context Pack

Cấu trúc docs được tổ chức theo 5 tầng:

- `0_agent/`: guardrails & workflow cho Agent/Copilot (đọc trước)
- `1_business/`: mục tiêu, phạm vi, persona, KPI
- `2_functional/`: màn hình, luồng, hành vi, acceptance criteria (FR mapping)
- `3_technical/`: API contract, data model, rules/validation, auth/rbac, error handling, NFR, traceability
- `4_coding_guidance/`: kiến trúc code, coding standards, logging, prompt mẫu, task list

Nguyên tắc: **không tự bịa** thêm tính năng/field/endpoint ngoài 5 tài liệu nguồn.
